### Code Example: Task Distribution

The following Python snippet demonstrates how a task might be enqueued to a specific planner using Redis Queue in MorningAI:

```python
from rq import Queue
from redis import Redis
import my_task_function

# Connect to Redis server
redis_conn = Redis(host='localhost', port=6379, db=0)
q = Queue('planner_tasks', connection=redis_conn)

# Enqueue the task with specific parameters
job = q.enqueue(my_task_function, args=('param1', 'param2'), timeout=600)

print(f"Task {job.id} enqueued to planner_tasks queue.")
```
