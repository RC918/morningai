# 如何使用 Python 計算斐波那契數列？

斐波那契數列是一個著名的數學序列，其中每個數字是前兩個數字的和。在编程和算法设计中，生成斐波那契序列是一个常见的问题，用来测试逻辑和循环控制的理解。在Python中，有几种方法可以计算斐波那契数列，包括递归、迭代和利用生成器。

## 方法1：递归

递归方法是最直观的解决方案，但由于其高时间复杂度，在处理大量数据时效率不高。

```python
def fibonacci_recursive(n):
    if n <= 1:
        return n
    else:
        return(fibonacci_recursive(n-1) + fibonacci_recursive(n-2))
```

## 方法2：迭代

相比递归，迭代方法更加高效，特别是对于大量数据的处理。

```python
def fibonacci_iterative(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 方法3：使用生成器

使用Python的生成器可以更优雅地实现斐波那契数列，并且在内存使用上更加高效。

```python
def fibonacci_generator():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
```

为了获取前N个斐波那契数，可以这样做：

```python
def get_fibonacci_numbers(limit):
    fib_sequence = []
    fib_gen = fibonacci_generator()
    for _ in range(limit):
        fib_sequence.append(next(fib_gen))
    return fib_sequence
```
