# 查看訂單歷史

查看訂單歷史是一項重要功能，使開發人員能夠追踪和分析MorningAI平台上的交易記錄。本文檔將指導您如何使用MorningAI的API和用戶界面來查詢和查看訂單歷史。

## 使用API查詢訂單歷史

MorningAI提供了一個REST API，允許開發者以編程方式查詢訂單歷史。以下是一個使用Python和Flask進行API調用的範例：

```python
import requests

def get_order_history(user_id):
    url = "https://api.morningai.com/orders/history"
    headers = {
        "Authorization": "Bearer your_access_token",
        "Content-Type": "application/json"
    }
    params = {"user_id": user_id}
    response = requests.get(url, headers=headers, params=params)
    
    if response.status_code == 200:
        return response.json()
    else:
        raise Exception("Failed to fetch order history")

# 使用示例
user_id = 'your_user_id'
order_history = get_order_history(user_id)
print(order_history)
```

請確保替換`your_access_token`和`your_user_id`為有效值。

## 通過用戶界面查看訂單歷史

除了API之外，開發者和終端用戶也可以通過MorningAI的用戶界面直接查看訂單歷史：

如果在調用API時收到401 Unauthorized錯誤，請檢查您的Access Token是否正確且未過期。您可能需要重新獲取或刷新Token。
