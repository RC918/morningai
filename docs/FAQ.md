## 取消订阅步骤

1. **登录MorningAI平台**: 首先，您需要登录到MorningAI平台。请确保使用与您的订阅关联的账户进行登录。

2. **访问账户设置**: 登录后，导航至页面右上角的用户菜单，并选择“账户设置”或类似选项。

3. **管理订阅**: 在账户设置页面中，寻找“订阅管理”或“我的订阅”部分。点击进入。

4. **取消订阅**: 在此页面，您将看到您当前的所有订阅列表。找到您想要取消的订阅，并点击旁边的“取消订阅”按钮。

5. **确认取消**: 系统可能会要求您确认取消操作。请仔细阅读任何警告或提示信息，并确认取消。

如果MorningAI支持通过API进行订阅管理，以下是一个示例Python脚本，用于调用API以取消订阅：

```python
import requests

def cancel_subscription(api_key, subscription_id):
    url = "https://api.morningai.com/subscriptions/cancel"
    headers = {"Authorization": f"Bearer {api_key}"}
    payload = {"subscription_id": subscription_id}

    response = requests.post(url, headers=headers, json=payload)

    if response.status_code == 200:
        print("Subscription cancelled successfully.")
    else:
        print(f"Failed to cancel subscription. Status code: {response.status_code}")

# 使用示例
api_key = "your_api_key_here"
subscription_id = "your_subscription_id_here"
cancel_subscription(api_key, subscription_id)
```

请替换`your_api_key_here`和`your_subscription_id_here`为实际值。
