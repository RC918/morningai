# Managing a Simple In-Memory Cache with TTL in Python

In the development of MorningAI, an efficient caching mechanism is crucial for enhancing performance and reducing latency. This FAQ provides a comprehensive guide on implementing a simple in-memory cache system in Python, which supports Time-To-Live (TTL) functionality. This feature is particularly useful for temporary data storage, where cached items are automatically invalidated after a specified duration.

## Understanding In-Memory Cache with TTL

An in-memory cache stores data temporarily in the RAM of the hosting server, providing rapid access to recently used or frequently accessed information. The TTL mechanism ensures that data doesn't stay in the cache indefinitely, which helps manage memory usage effectively by automatically removing expired items.

## Implementing the Cache Class

Below is an example implementation of a basic in-memory cache class with TTL support in Python. This class provides methods to set, get, and automatically delete expired cache entries based on their TTL.

```python
import time

class InMemoryCacheWithTTL:
    def __init__(self):
        self.cache = {}
        self.ttl = {}

    def set(self, key, value, ttl=3600):
        self.cache[key] = value
        self.ttl[key] = time.time() + ttl

    def get(self, key):
        if key in self.cache and time.time() < self.ttl[key]:
            return self.cache[key]
        else:
            # Optionally, remove the expired item
            self.remove(key)
            return None

    def remove(self, key):
        if key in self.cache:
            del self.cache[key]
            del self.ttl[key]

    def cleanup(self):
        # Optional method to manually remove all expired items
        current_time = time.time()
        keys_to_delete = [key for key, expiry in self.ttl.items() if current_time >= expiry]
        for key in keys_to_delete:
            self.remove(key)
```

### Usage Example:

```python
cache = InMemoryCacheWithTTL()
cache.set("key1", "value1", ttl=10)  # Set item with 10 seconds TTL
print(cache.get("key1"))  # Returns 'value1'
time.sleep(11)  # Wait until the item expires
print(cache.get("key1"))  # Returns None since the item has expired
```

## Common Troubleshooting Tips

- **Cache Item Not Found**: Ensure the TTL has not elapsed since setting the item. Use larger TTL values for testing.
- **Memory Usage Increases**: Regularly call the `cleanup()` method to remove expired items or ensure items have reasonable TTLs.
- **Performance Issues**: While this simple cache implementation is suitable for small-scale applications, consider using dedicated caching solutions like Redis for more complex requirements.
