# 如何重設密碼？

當您需要重設 MorningAI 平台上的密碼時，可以通過以下步驟輕鬆完成。這一過程旨在保護您的賬戶安全，同時確保只有賬戶擁有者能夠重設密碼。

## 步驟 1: 訪問登錄頁面

首先，訪問 MorningAI 的登錄頁面。在登錄表單下方，您會看到一個「忘記密碼？」的鏈接。

```plaintext
https://morningai.example.com/login
```

## 步驟 2: 輸入您的電子郵件地址

點擊「忘記密碼？」鏈接後，系統會要求您輸入與您的賬戶關聯的電子郵件地址。請確保輸入正確的電子郵件地址，然後點擊提交。

```html
<input type="email" name="email" required placeholder="Enter your email address">
<button type="submit">Submit</button>
```

## 步驟 3: 檢查您的電子郵件

提交您的電子郵件地址後，MorningAI 將向該地址發送一封包含重設密碼鏈接的電子郵件。打開該郵件，並點擊其中的鏈接來進行下一步。

## 步驟 4: 設置新密碼

點擊電子郵件中的鏈接後，您將被導向到一個新頁面，在這裡您可以設置新的密碼。請按照提示輸入新密碼並提交。

```html
<input type="password" name="new-password" required placeholder="Enter new password">
<input type="password" name="confirm-password" required placeholder="Confirm new password">
<button type="submit">Reset Password</button>
```

## 常見故障排除

**未收到重設密碼郵件？**

- 檢查您的垃圾郵件文件夾。
- 確保您使用的是與 MorningAI 賬戶關聯的電子郵件地址。
- 若仍未收到，請稍等幾分鐘再次檢查，或嘗試重新提交重設請求。

**重設鏈接無法使用？**

- 重設鏈接可能因時間過長而失效（通常在發送後24小時內）。若此情況發生，請重新啟動重設密碼過程。
- 確認你是否點擊了最近一封包含重設鏈接的電子郵件中的鏈接。
