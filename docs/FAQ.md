# 如何使用 Python 實作快速排序演算法？

快速排序（Quick Sort）是一種高效的排序演算法，採用分治法（Divide and Conquer）的策略來把一個序列分為較小和較大的兩部分，然後進行遞迴排序。這裡提供一個基於 Python 的快速排序實作方法，幫助開發者在 MorningAI 平台中有效地應用。

## 快速排序演算法的工作原理

1. 選擇一個元素作為"基準"（pivot）。
2. 重新排列數組，所有比基準值小的元素擺放在基準前面，所有比基準值大的元素擺在基準的後面（相同的數可以到任一邊）。在這個分割之後，該基準就處於數組的中間位置。這個稱為分割（partition）操作。
3. 遞迴地（recursive）把小於基準值元素的子序列和大於基準值元素的子序列排序。

## Python 實作範例

以下是快速排序演算法的 Python 實現：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 測試代碼
if __name__ == "__main__":
    test_array = [3, 6, 8, 10, 1, 2, 1]
    print("Original array:", test_array)
    print("Sorted array:", quick_sort(test_array))
```

## 常見問題與疑難排解

### 問題1：遞迴深度錯誤 `RecursionError: maximum recursion depth exceeded in comparison`
如果遇到此錯誤，可能是因為待排序數組太大或選取的基準點不恰當導致遞迴深度過深。可以嘗試增加 Python 遞迴深度限制：

```python
import sys
sys.setrecursionlimit(1500)
```

### 問題2：效率問題
在最壞情況下（例如已經是有序或逆序），快速排序的時間複雜度會退化到O(n^2)。可以通過選擇更好的基準點策略來優化，例如使用三數中值分割法。

### 問題3：不穩定排序
由於相等元素可能會因為分割而被分到基準點的任一側，因此快速排序是一個不穩定的排序算法。如果需要穩定性，在特定情況下可能需要考慮其他排序算法。
