## Code Examples

### Parsing and Validation

The following Python example demonstrates how a piece of code might parse and validate a JSON object using a predefined schema:

```python
import json
from jsonschema import validate
from jsonschema.exceptions import ValidationError

# Example schema
schema = {
    "type": "object",
    "properties": {
        "name": {"type": "string"},
        "age": {"type": "number"},
    },
    "required": ["name", "age"]
}

# Sample JSON string
json_str = '{"name": "John Doe", "age": 30}'

try:
    # Parse JSON string
    data = json.loads(json_str)
    
    # Validate against schema
    validate(instance=data, schema=schema)
    
    print("JSON is valid and conforms to the schema.")
except json.JSONDecodeError:
    print("Failed to decode JSON.")
except ValidationError as e:
    print(f"JSON validation error: {e.message}")
```
