# 如何實作 RESTful API 的身份驗證？

在開發 RESTful API 時，確保每個請求都來自於經過授權的使用者是非常重要的。MorningAI 平台提供了一種基於 Flask 和 JWT (JSON Web Tokens) 的身份驗證實現方案。這份指南將幫助開發者了解如何在 MorningAI 的架構中實作和使用身份驗證。

## 基本概念

在 Flask 應用中實作 JWT 身份驗證涉及到生成和驗證令牌的過程。當用戶成功登入後，系統將生成一個 JWT 令牌並返回給用戶。此後，用戶在隨後的請求中需要在 HTTP 頭部帶上這個令牌以通過身份驗證。

## 實作步驟

### 步驟1: 安裝依賴

首先，需要在你的 Flask 應用中安裝 JWT 相關的 Python 庫。可以使用 pip 進行安裝：

```bash
pip install PyJWT flask
```

### 步驟2: 配置 Flask 和 JWT

接下來，在你的 Flask 應用中配置 JWT。以下是一個簡單的配置示例：

```python
from flask import Flask, jsonify, request
import jwt
import datetime

app = Flask(__name__)
app.config['SECRET_KEY'] = 'your_secret_key'

def encode_auth_token(user_id):
    try:
        payload = {
            'exp': datetime.datetime.utcnow() + datetime.timedelta(days=0, seconds=5),
            'iat': datetime.datetime.utcnow(),
            'sub': user_id
        }
        return jwt.encode(
            payload,
            app.config.get('SECRET_KEY'),
            algorithm='HS256'
        )
    except Exception as e:
        return e

@app.route('/login', methods=['POST'])
def login():
    auth_data = request.json
    user_id = auth_data.get('user_id')
    token = encode_auth_token(user_id)
    return jsonify({'token': token.decode('UTF-8')})

if __name__ == '__main__':
    app.run()
```

### 步驟3: 驗證請求

每次接收到需要認證的請求時，都需要從 HTTP 頭部讀取並解析 JWT 令牌。以下是一個簡單的例子來展示如何進行：

```python
from flask import Flask, request, jsonify
import jwt

app = Flask(__name__)
app.config['SECRET_KEY'] = 'your_secret_key'

def decode_auth_token(auth_token):
    try:
        payload = jwt.decode(auth_token, app.config.get('SECRET_KEY'), algorithms=['HS256'])
        return payload['sub']
    except jwt.ExpiredSignatureError:
        return 'Signature expired. Please log in again.'
    except jwt.InvalidTokenError:
        return 'Invalid token. Please log in again.'

@app.route('/secure', methods=['GET'])
def secure_endpoint():
    auth_header = request.headers.get('Authorization')
    if auth_header:
        auth_token = auth_header.split(" ")[1]
        user_id = decode_auth_token(auth_token)
        return jsonify({'user_id': user_id}), 200
    else:
        return jsonify({'message': 'Missing token.'}), 403

if __name__ == '__main__':
    app.run()
```

## 常見故障排除

**問題**: 收到 "Invalid token" 錯誤。
**解決方案**: 確保發送給服務器的令牌完整無誤，且前端在發送請求時要正確設置 `Authorization` 頭部。

**問題**: 令牌快速過期。
**解決方案**: 在生成令牌時，`exp` 欄位設置得過短會導致此問題。根據需求調整有效期。
