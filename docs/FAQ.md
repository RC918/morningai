# 如何啟用雙因素驗證？

雙因素驗證（2FA）提供了額外的安全層，要求用戶在登錄過程中提供兩種身份驗證形式。在MorningAI平台上啟用2FA，可以大大增強您賬戶的安全性。本文將指導您如何在MorningAI上設置和使用雙因素驗證。

## 啟用步驟

1. **登錄到您的MorningAI賬戶：**
首先，訪問MorningAI並使用您的憑據登錄。

2. **訪問設置：**
在主界面的右上角，點擊您的用戶名或頭像，然後選擇「設置」。

3. **選擇安全選項：**
在設置菜單中，尋找「安全性」或類似命名的選項並點擊進入。

4. **啟用雙因素驗證：**
在「安全性」頁面中找到「雙因素驗證」選項並啟用。系統可能會要求您輸入密碼確認此操作。

5. **掃描QR碼：**
使用兼容的雙因素認證應用程序（如Google Authenticator或Authy）掃描顯示的QR碼。這會將您的MorningAI賬戶添加到該應用程序中。

6. **輸入驗證碼完成設定：**
最後，在MorningAI提供的空格中輸入應用程序生成的6位數驗證碼以完成設定。

## 常見問題解決

- **掃描QR碼時出現問題怎麼辦？**
    - 確保使用的是兼容的二次驗證APP。
    - 檢查相機權限是否已為該APP開啟。
    - 嘗試手動輸入提供的秘鑰代替掃描。

- **沒有收到二次驗證代碼怎麼辦？**
    - 確保手機時間與互聯網時間同步。
    - 關閉再重新開啟您的二次驗證APP。

- **更換手機後如何轉移二次驗證？**
    - 在更換手機之前，務必從MorningAI安全設置中獲取並備份您的恢復代碼。
    - 在新設備上重新設置二次驗證APP並使用恢復代碼恢復賬戶。
