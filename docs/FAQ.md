# Event Sourcing (事件溯源模式)

Event Sourcing 是一种软件架构模式，用于记录实体状态变更的全部历史作为一系列事件。与传统的基于状态的存储（即直接存储最终状态）不同，事件溯源模式通过重放这些事件来恢复实体的当前状态。这种方法提供了对系统状态变化的完整视角，允许开发者不仅看到当前状态，而且理解达到该状态的过程。

## 1. 基本概念

在Event Sourcing模式中，所有对系统状态的更改都以事件的形式被捕获。每个事件都代表了一个不可变的事实，描述了一个过去发生的动作。通过将这些事件应用于初始状态或上一个已知状态，可以重建或查询实体的历史状态。

## 3. 常见问题解决

**Q: 如何处理大量积累的事件导致的性能问题？**

A: 实施快照机制是减少重放旧事件以恢复当前状态所需时间的常用方法。定期创建实体当前状态的快照，并在重建状态时从最近快照开始而非从头开始。

**Q: 如果发现事件记录错误怎么办？**

A: 由于事件代表系统中发生过的不可变历史，因此不应直接修改或删除错误事件。相反，应该引入新事件来“修正”之前错误事件带来的影响。
