# 如何使用 Python 實作快速排序演算法？

快速排序是一種高效的排序演算法，採用分治策略在平均狀況下擁有O(n log n)的時間複雜度。此方法首先選擇一個“基準”元素，然後將數列分成兩部分，一部分包含所有小於基準的元素，另一部分包含所有大於基準的元素。這一過程稱為“劃分”。接著，演算法遞迴地對這兩部分進行快速排序，從而完成整個數列的排序。

## 快速排序實作

以下是使用 Python 實現快速排序的基本代碼示例：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 示例使用
array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quick_sort(array)
print(sorted_array)
```

此代碼段首先檢查輸入數組`arr`的長度。如果長度小於或等於1，則無需進行排序，直接返回。否則，選擇中間元素作為基準（pivot），並根據其值將數組分成左、中、右三部分。然後對左右兩側的數組遞迴調用`quick_sort`函數，最後將三個部分合併起來返回。

## 常見問題排解

### 效能問題

- **大數據集性能**：在處理非常大的數據集時，快速排序可能會因為遞迴深度太大而導致性能問題。可以通過增加系統的遞迴深度限制或使用非遞迴版本來解決。
  
```python
import sys
sys.setrecursionlimit(10000) # 提高遞迴深度限制
```

### 不穩定排序

- 快速排序是一種不穩定的排序方法，意味著具有相同鍵值的元素在排序前後可能會改變順序。如果需要穩定性，考慮使用归并排序或計數排序等其他算法。
