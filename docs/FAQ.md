# 如何使用 Python 實作快速排序演算法？

快速排序（Quick Sort）是一種高效的排序算法，採用分治法（Divide and Conquer）的策略來把一個序列分為較小和較大的2個子序列，然後遞迴地排序兩個子序列。快速排序在平均狀況下的時間複雜度為O(n log n)，並且在實際應用中表現出色。

## 快速排序演算法原理

快速排序通過選擇一個元素作為"基準點"（pivot），將待排序數列分成兩部分。一部分包含所有小於基準點的元素，另一部分包含所有大於基準點的元素。這一步稱為"劃分"（partitioning）。接下來，透過遞迴地對這兩部分數列再次應用快速排序，直到序列被細分至只包含單個元素，即完成排序。

## Python 實現示例

以下提供了使用 Python 實作快速排序的基本示例代碼：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 使用範例
array = [3, 6, 8, 10, 1, 2, 1]
sorted_array = quick_sort(array)
print(sorted_array)
```

此代碼首先檢查輸入的數組長度是否小於或等於1，如果是，則直接返回該數組（因為它已經是有序的）。然後，選擇數組中間的元素作為基準點，並根據其值將數組分成左、中、右三部分。最後，遞迴地對左右兩側的數組進行同樣操作，並將結果連接起來返回。

## 常見問題解決提示

- **記憶體使用**: 在某些極端情況下（例如已經幾乎有序的數組），快速排序可能會使用較多記憶體。在這些情況下，可以考慮使用其他排序演算法或者優化快速排序算法（如使用三數中值分割法來選取基準點）。
- **遞迴深度**: Python 默認有遞迴深度限制，若要處理大量數據可能會觸發`RecursionError`。可以通過`sys.setrecursionlimit()`函式提高限制。
