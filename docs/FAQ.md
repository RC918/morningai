# 如何聯繫客服？

當您在使用MorningAI平台時遇到問題或需要專業的技術支援，我們提供多種方式讓您能夠方便快捷地聯繫到我們的客服團隊。

## 1. 電子郵件

您可以通過發送電子郵件至support@morningai.com與我們的客服團隊取得聯繫。請在郵件中詳細說明您遇到的問題或需要幫助的具體情況，這樣我們可以更快速、更有效地為您提供所需的協助。

## 2. 平台內消息系統

MorningAI平台提供了一個內置的消息系統，讓您能夠直接在平台上向我們的客服團隊發送消息。您可以通過訪問平台主界面右上角的“幫助”或“聯繫客服”按鈕來使用此功能。

## 3. 社交媒體和即時通訊工具

我們也在多個社交媒體平台和即時通訊工具上設有官方帳號，包括但不限於Telegram、LINE和Messenger。您可以通過這些渠道直接與我們聯繫。請訪問[官方網站](https://morningai.com/contact)查看所有可用的聯繫方式及相應連結。

## 常見問題解決提示

- **無法登入**：請確認您使用的登入資訊正確無誤。如果忘記密碼，請使用「忘記密碼」功能重置。
- **功能出現錯誤**：嘗試清除瀏覽器緩存並重新加載頁面。如果問題持續存在，請截圖並附在向客服發送的消息中。
- **性能問題**：確保您的網絡連接穩定。對於大型操作，可能需要稍長時間等待處理完成。

若上述方法均無法解決您的問題，請不要猶豫立即聯繫我們的客服團隊以獲得進一步協助。
