# 如何在 React 中使用 useEffect Hook

`useEffect` Hook 是 React 函数组件中用于处理副作用的一种方式。它可以用于数据获取、订阅或手动更改 DOM 等场景。这个 Hook 让你能够在组件渲染之后执行某些操作，这些操作可以反映在 DOM 更新之前或之后。

## 基本用法

在函数组件中，`useEffect` 接收两个参数：一个是包含副作用逻辑的函数，另一个是依赖数组。当依赖项改变时，副作用函数就会被执行。

```jsx
import React, { useState, useEffect } from 'react';

function ExampleComponent() {
  const [count, setCount] = useState(0);

  // 使用 useEffect 进行副作用操作
  useEffect(() => {
    // 更新文档标题
    document.title = `您点击了 ${count} 次`;
  }, [count]); // 依赖数组里有 count，只要 count 变化，就会重新运行

  return (
    <div>
      <p>您点击了 {count} 次</p>
      <button onClick={() => setCount(count + 1)}>
        点击我
      </button>
    </div>
  );
}
```

## 清理副作用

有些副作用是需要清理的（例如，定时器、订阅等）。为此，`useEffect` 的函数可以返回一个清理函数，React 将在组件卸载或副作用重新执行前调用这个清理函数。

```jsx
useEffect(() => {
  const timerID = setInterval(
    () => tick(),
    1000
  );

  // 清理函数
  return function cleanup() {
    clearInterval(timerID);
  };
}, []); // 如果依赖数组为空，则副作用只在挂载和卸载时执行
```

## 常见问题解决

**问题**: 我在 `useEffect` 中发起了网络请求，但遇到了“内存泄漏”的警告怎么办？

**解决方案**: 这通常发生在组件卸载后异步操作仍然尝试更新组件状态的情况下。确保在组件卸载后取消所有订阅和异步任务：

```jsx
useEffect(() => {
  let isMounted = true;

  fetchData().then(data => {
    if (isMounted) {
      // 更新状态
    }
  });

  return () => {
    isMounted = false;
  };
}, []); // 注意依赖项列表
```

**问题**: 如何确保 `useEffect` 不会在每次渲染后都执行？

**解决方案**: 确保正确地使用依赖项数组。如果你希望 `useEffect` 只在组件挂载和卸载时执行，请传递一个空数组（[]）作为第二个参数。

通过掌握 `useEffect` 的使用，你可以有效地在 React 函数组件中处理各种副作用场景。
