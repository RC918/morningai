## Understanding Planner Distribution

The MorningAI platform utilizes an autonomous agent system for code generation, task orchestration, and real-time execution. The planner distribution refers to how these tasks are allocated and managed across different agents, ensuring efficient load balancing and task execution.

### Key Components:

- **Autonomous Agents**: Individual agents responsible for executing specific tasks.
- **Task Orchestrator**: Utilizes LangGraph to manage workflow among agents.
- **Redis Queue (RQ)**: Manages task queues, ensuring tasks are executed in a timely manner.

## Code Examples

### Verifying Task Allocation

To verify that tasks are being correctly distributed, you can inspect the Redis Queue (RQ) dashboard. This requires setting up RQ-dashboard if not already configured.

```bash
rq-dashboard
```

This command launches a web interface showing queued tasks, their status, and which worker is handling them.

### Monitoring Agent Workflows

You can monitor agent workflows by logging into the LangGraph orchestrator. Ensure you have necessary permissions to access this tool.

```python
# Example Python snippet to log workflow status
from morningai.langgraph import WorkflowMonitor

monitor = WorkflowMonitor(api_key="your_api_key")
status = monitor.get_workflow_status(workflow_id="your_workflow_id")
print(status)
```

## Common Troubleshooting Tips

### Tasks Not Being Distributed

- **Check Worker Availability**: Ensure that Gunicorn workers are running with sufficient resources. You can scale workers using:
  
  ```bash
  gunicorn -w 4 myproject:app
  ```

- **Inspect Redis Queue**: Verify that Redis is up and running without errors. Check for any stuck or failed jobs in the RQ dashboard.

### Inconsistent Task Execution

- **Monitor System Resources**: Ensure your deployment environment on Render.com has sufficient resources allocated.
  
- **Review LangGraph Workflows**: Verify that workflows are correctly defined and there are no logical errors causing unexpected behavior.
