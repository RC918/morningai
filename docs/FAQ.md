## Understanding Planner Distribution

MorningAI utilizes a sophisticated task orchestration system, powered by Redis Queue (RQ), to manage and distribute tasks across multiple planners (agents). Each planner is responsible for executing specific tasks, such as code generation, documentation management, or handling multi-platform integrations. The distribution mechanism ensures that workloads are balanced, preventing any single planner from becoming a bottleneck.

### Key Components

- **Redis Queue (RQ):** Manages the queue of tasks awaiting processing.
- **LangGraph:** Orchestrates the workflow among different agents.
- **Planners:** Autonomous agents assigned to execute specific tasks.

## Verifying Task Distribution

To verify that tasks are being distributed correctly among planners, you can use the following steps:

1. **Monitor RQ Dashboard:**

First, ensure you have access to the RQ Dashboard. This web interface provides a real-time overview of the queues, including the number of jobs processed by each worker (planner).

```shell
# Accessing RQ Dashboard

```

2. **Check Planner Workload:**

You can programmatically check the workload of each planner using Python scripts that interact with RQ and Redis. Below is an example script that lists the number of tasks each planner is currently processing:

```python
from rq import Connection, Worker
import redis

redis_conn = redis.Redis()

with Connection(redis_conn):
    workers = Worker.all()
    for worker in workers:
        print(f"Planner {worker.name} is processing {len(worker.jobs)} tasks")
```

3. **Review Logs:**

Logs provide invaluable insights into how tasks are distributed and executed. Ensure logging is enabled in your Flask application settings and review the logs regularly.
