# 如何更改語言設定？

MorningAI支持多語言功能，讓開發者能夠根據用戶偏好設置界面語言。本文將指導您如何在MorningAI平台上更改語言設定。

## 步驟1：找到語言配置文件

MorningAI的語言配置文件通常位於`config/locales`目錄下。這些文件以`.json`或`.yml`格式存儲，每個文件對應一種支持的語言。

例如，若要查看英文和中文的配置文件，您可能會找到如下文件：

- `config/locales/en.json` (英文)
- `config/locales/zh.json` (中文)

## 步驟2：修改配置文件

打開您希望更改的語言文件。您可以添加新的鍵值對，或修改現有的條目來更改該語言下特定文字的顯示。

例如，若要修改中文界面上"Welcome"的翻譯，可以在`zh.json`中找到相應的鍵（假設是`"welcome"`），並修改其值：

```json
{
  "welcome": "欢迎使用MorningAI"
}
```

## 步驟3：應用更改

修改配置文件後，需要重新啟動應用程序以使更改生效。如果您使用Gunicorn作為Web服務器，可以通過以下命令重啟：

```bash
gunicorn --reload
```

注意：實際重啟命令可能根據您的部署環境有所不同。
