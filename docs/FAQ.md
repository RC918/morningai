# 如何使用 Kafka 實作訊息佇列

Apache Kafka 是一個分布式事件流平台，能夠高效處理大量數據的讀寫，廣泛用於訊息佇列（Message Queuing）的場景中。以下是在 MorningAI 平台中使用 Kafka 來實作訊息佇列的步驟和範例。

## 瞭解 Kafka 架構

Kafka 運作於一個分布式系統架構上，主要包括以下元素：

- **Producer**: 負責發送消息到 Kafka topics。
- **Consumer**: 從 topics 讀取消息。
- **Broker**: Kafka 集群中的伺服器節點。
- **Topic**: 消息的類別名稱，在 Kafka 內部以分區（Partition）的形式儲存。

## 步驟 1: 安裝和配置 Kafka

首先，確保你已經在你的開發環境安裝了 Kafka。可以從 [Apache Kafka 官方網站](https://kafka.apache.org/downloads) 下載相應版本進行安裝。

```bash
# 下載並解壓 Kafka
tar -xzf kafka_2.13-2.8.0.tgz
cd kafka_2.13-2.8.0

# 啟動 Zookeeper 服務
bin/zookeeper-server-start.sh config/zookeeper.properties

# 在另一個終端啟動 Kafka 服務
bin/kafka-server-start.sh config/server.properties
```

## 步驟 2: 創建 Topic

在傳送或接收消息之前，需要創建一個或多個 Topics。

```bash
bin/kafka-topics.sh --create --partitions 1 --replication-factor 1 --topic morningai-messages --bootstrap-server localhost:9092
```

## 步驟 3: 實作 Producer 和 Consumer

在 MorningAI 平台中，使用 Python 語言通過 `kafka-python` 庫與 Kafka 溝通。

### 安裝 kafka-python

```bash
pip install kafka-python
```

### Producer 範例

將以下程式碼保存至 `producer.py`，負責向 `morningai-messages` topic 發送消息。

```python
from kafka import KafkaProducer

producer = KafkaProducer(bootstrap_servers='localhost:9092')
topic_name = 'morningai-messages'

# 發送一條訊息到指定的 topic
producer.send(topic_name, b'Hello, MorningAI!')
producer.flush() # 確保所有異步訊息都已發送完成
```

### Consumer 範例

將以下程式碼保存至 `consumer.py`，從 `morningai-messages` topic 讀取消息。

```python
from kafka import KafkaConsumer

topic_name = 'morningai-messages'
consumer = KafkaConsumer(topic_name, bootstrap_servers='localhost:9092')

for message in consumer:
    print(f"Received message: {message.value.decode('utf-8')}")
```

## 常見問題排解

**問題**: Producer 發送消息後，Consumer 無法接收到消息。

**解決方案**:

1. 確認所有服務（Zookeeper、Kafka）都正在運行。
2. 確保 Producer 和 Consumer 使用相同的 Bootstrap Server 地址和 Port。
3. 檢查 Topic 名稱是否正確無誤。
