# 如何使用 Python 實作快速排序演算法

快速排序（Quick Sort）是一種高效的排序演算法，採用分治法（Divide and Conquer）的策略來把一個序列分為較小和較大的2個子序列，然後遞歸地排序兩個子序列。本節將指導您如何在Python中實現快速排序演算法。

## 快速排序原理

1. 從序列中挑選一個元素作為"基準"（pivot）。
2. 重新排列序列，所有比基準值小的元素擺放在基準前面，所有比基準值大的元素擺在基準的後面（相同的數可以到任一邊）。在這個分割結束之後，該基準就處於序列的中間位置。這個稱為分割（partition）操作。
3. 遞歸地（recursive）把小於基準值元素的子序列和大於基準值元素的子序列排序。

## Python 實現

以下是快速排序演算法的Python實現示例：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 使用範例
arr = [3, 6, 8, 10, 1, 2, 1]
print("Sorted array:", quick_sort(arr))
```

## 常見問題與解決方法

### 問題：當數據集很大時，執行速度變慢。
**解決方法**：嘗試增加堆棧大小或使用非遞歸版本的快速排序來優化性能。

### 問題：`RecursionError: maximum recursion depth exceeded in comparison`
**解決方法**：此錯誤表示您的程序超出了Python默認的遞歸深度限制。可以通過以下代碼提高限制：

```python
import sys
sys.setrecursionlimit(1500)
```

### 問題：如何選擇一個好的基準值？
**解決方法**：理想情況下，基準值應該能將數組等分，減少算法執行時間。通常使用第一個元素、最後一個元素、中間元素或隨機元素作為基準。
