# 如何查看訂單歷史？

在使用MorningAI平台開發過程中，查看訂單歷史是一個常見的需求。這不僅有助於追蹤用戶行為，也方便了數據分析和報告的生成。以下指南將引導開發者如何在MorningAI平台上查看訂單歷史。

## 查詢訂單歷史

MorningAI利用PostgreSQL（Supabase）作為數據庫解決方案，支持行級安全性（Row Level Security, RLS），使得查詢操作既安全又高效。以下是一個基本的查詢示例，假設您已經配置好了相關的數據庫表格和權限。

### 代碼示例

首先，確保您已經在`backend`目錄下的Python Flask應用中設置了數據庫連接。以下示例使用Flask SQLAlchemy來執行查詢：

```python
from flask_sqlalchemy import SQLAlchemy
from models import OrderHistory  # 假定您已經根據您的模型定義了OrderHistory模型

db = SQLAlchemy()

def get_order_history(user_id):
    """根據用戶ID查詢訂單歷史"""
    try:
        order_history = db.session.query(OrderHistory).filter_by(user_id=user_id).all()
        return order_history
    except Exception as e:
        print(f"Error retrieving order history: {e}")
        return None
```

## 常見問題排解

### 數據庫連接失敗

確保`.env`文件或您的環境變量中包含正確的數據庫連接信息。例如：

```plaintext
DATABASE_URL="postgresql://USERNAME:PASSWORD@HOST/DATABASE"
```

### 查詢返回空或錯誤結果

- 確保`OrderHistory`模型正確映射到您的數據庫結構。
- 檢查是否有對應用戶ID存在於訂單歷史中。
- 檢視是否啟用了行級安全性（RLS），並確認相關政策是否允許當前用戶訪問這些資料。
