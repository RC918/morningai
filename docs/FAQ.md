# 如何更新個人資料？

在MorningAI平台上更新個人資料，是一個簡單且直觀的過程。本指南將幫助開發者了解如何透過我們的API或用戶界面來更新他們的個人資訊。

## 通過用戶界面更新

1. 登入您的MorningAI帳戶。
2. 導航至**設定**頁面，通常可從主導航菜單找到。
3. 在**個人資料**或**我的帳戶**區域中，點擊**編輯**或類似選項。
4. 更新您的資料，如名字、電子郵件地址、密碼等。
5. 點擊**保存**以應用更改。

## 通過API更新

如果您是開發者且偏好透過API更新個人資料，可以按照以下步驟：

```python
import requests

# 設定您的API端點
api_url = "https://api.morningai.com/user/profile/update"

# 您的API令牌
api_token = "your_api_token_here"

# 需要更新的資料
payload = {
    "name": "新名字",
    "email": "newemail@example.com",
    # 其他可更新的字段...
}

headers = {
    "Authorization": f"Bearer {api_token}",
    "Content-Type": "application/json"
}

response = requests.post(api_url, json=payload, headers=headers)

if response.status_code == 200:
    print("個人資料已成功更新")
else:
    print(f"錯誤: {response.text}")
```

### 常見問題排解

#### 更新不生效

如果您通過用戶界面或API進行了更改，但更改似乎沒有生效：

- 確保您已正確保存更改。
- 清除瀏覽器快取後再次嘗試。
- 檢查是否有任何服務斷開或網絡問題。

#### API認證錯誤

如果在使用API時收到認證錯誤：

- 確保您使用的是正確的API令牌。
- 檢查令牌是否已過期或被撤銷。
