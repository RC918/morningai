# 什麼是 Docker 容器化技術？

Docker 是一種開源的容器化技術，允許開發者將應用程序及其依賴項打包在一個輕量級、可移動的容器中。這使得應用程序可以在任何機器上以相同的方式運行，無論該機器的環境如何。Docker 容器化技術有助於解決“在我的機器上運行正常”問題，確保軟件的一致性和效率。

## Docker 的關鍵特性

- **隔離性**: 每個容器都在自己的環境中運行，與其他容器分開。
- **輕量級**: 容器共享主機OS的核心，不需要像虛擬機那樣模擬整個操作系統，因此更加高效。
- **可移植性**: 由於容器包含所有必要的依賴項，它們可以在任何支持Docker的環境中運行。
- **版本控制和可復原**: Docker使用映像(image)文件來創建容器。映像可以版本控制、存儲、傳遞和更新。

## Docker 在 MorningAI 中的使用

MorningAI平台利用Docker容器化技術來確保代碼生成、FAQ生成和文檔管理等服務的一致性和高效運行。以下是利用Docker啟動MorningAI環境的基本步驟：

```bash
# 拉取MorningAI项目的Docker映像
docker pull rc918/morningai:latest

# 使用Docker运行MorningAI
docker run -d -p 8080:80 rc918/morningai:latest
```

此命令將會從Docker Hub拉取最新版本的`morningai`映像，并在分離模式下運行它，映射主機的8080端口到容器的80端口。

## 常見故障排除

**1. 容器無法啟動**

確保所有必要的環境變量都已正確設置。查看容器日志以獲取錯誤詳情：

```bash
docker logs <container_id>
```

**2. 端口衝突**

如果8080端口已被其他應用占用，可以通過修改`docker run`命令中的端口映射來解決：

```bash
docker run -d -p <other_port>:80 rc918/morningai:latest
```

將`<other_port>`替換成其他未被占用的端口。

**3. 映像拉取失敗**

確保Docker客戶端登錄並且有權訪問rc918/morningai映像。如果是私有庫存，需要先執行`docker login`。
