# 如何使用 Python 實作快速排序演算法？

快速排序（Quick Sort）是一種高效的排序演算法，採用分治法（Divide and Conquer）的策略來把一個序列分為較小和較大的兩部分，然後遞迴地排序兩部分。本文將介紹如何在 Python 中實作快速排序演算法並提供相關代碼示例。

## 快速排序演算法原理

1. 從數列中挑出一個元素，稱為 "基準"（pivot）。
2. 重新排列數列，所有元素比基準值小的擺放在基準前面，所有元素比基準值大的擺在基準的後面（相同的數可以到任一邊）。在這個分割結束之後，該基準就處於數列的中間位置。這個稱為分割（partition）操作。
3. 遞迴地（recursive）把小於基準值元素的子數列和大於基準值元素的子數列排序。

## Python 實作範例

以下是快速排序演算法的 Python 實作：

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 使用示例
arr = [3, 6, 8, 10, 1, 2, 1]
print(quick_sort(arr))
```

此代碼段首先檢查陣列長度，如果為 `1` 或更小，則直接返回，因為單個元素自然是已排序的。接著選擇陣列中間的元素作為基準點，並根據其將陣列劃分為左、中、右三部分，最後遞迴地對左右兩側進行相同操作。

## 常見問題與故障排除

**Q: 執行快速排序時遇到最大遞迴深度錯誤怎麼辦？**

A: Python 預設有一個遞迴調用的深度限制，以防止無限遞迴導致棧溢出。如果您碰到這個問題，可以嘗試增加遞迴限制：

```python
import sys
sys.setrecursionlimit(1500)
```

**Q: 如何改善快速排序的性能？**

A: 選擇不同的基準點策略可以改善性能。例如，始終選擇中間元素作為基準點可能不是最佳選擇，特別是對於已部分排序的數組。考慮使用“三數中值”（median-of-three）方法來選取基準點或隨機選取基準點以提高效率。
