# Reports Index

This directory contains various reports generated during the development and assessment of MorningAI.

## Report Categories

### CTO Reports

Technical assessments, strategic plans, and approval documents from CTO reviews.

- [CTO Reports Directory](cto/README.md)

### Coverage Reports

Test coverage reports and analysis.

- [Coverage Reports Directory](../coverage/) (located in `docs/coverage/`)

### Security Reports

Security audits and assessments.

- [Security Reports Directory](../security/) (located in `docs/security/`)

## Adding New Reports

When adding new reports:

1. Place the report in the appropriate subdirectory
2. Update the relevant README.md index file
3. Follow the naming convention: `CATEGORY_DESCRIPTION_DATE.md`
