# MorningAI System Architecture

MorningAI's architecture is designed to be robust, scalable, and efficient, supporting the autonomous generation of code, FAQ documentation, and real-time task orchestration among other features. Here’s a detailed overview of its components and how they interact within the system.

## Overview

The platform utilizes a multi-layered architecture comprising a React-based frontend, a Python Flask backend, PostgreSQL (Supabase) for database management, Redis Queue (RQ) for task queuing, LangGraph for orchestration, and OpenAI's GPT-4 for AI-driven content generation. Deployment is managed on Render.com with continuous integration and continuous deployment (CI/CD) practices.

### Frontend

- **Technology Stack**: React with Vite and TailwindCSS for fast development cycles and responsive design.
- **Path**: `/frontend`
- **Key Files**:
  - `src/App.jsx`: Entry point for the React application.
  - `vite.config.js`: Configuration for Vite.
  
```javascript

  return <div className="app">Welcome to MorningAI</div>;
```

### Backend

- **Technology Stack**: Python with Flask framework and Gunicorn as the WSGI HTTP Server.
- **Path**: `/backend`
- **Key Files**:
  - `app.py`: Main Flask application file.
  - `gunicorn.conf.py`: Gunicorn configuration for multi-worker support.

```python
# app.py example
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello_world():
    return 'Hello, MorningAI!'

if __name__ == '__main__':
    app.run()
```

### Database

- **Technology Used**: PostgreSQL with Supabase, enhancing PostgreSQL with Row Level Security (RLS) and pgvector for vector memory storage.
- **Integration Point**: Data is integrated through Flask SQLAlchemy models in the backend.

### Queue System

- **Technology Used**: Redis Queue (RQ) is employed for managing background tasks with worker heartbeat monitoring to ensure reliability.
- **Path**: `/queue`
- **Example Usage**:
  
```python
from redis import Redis
from rq import Queue

redis_conn = Redis()
q = Queue(connection=redis_conn)

result = q.enqueue('my_function', args=(my_arg,), timeout=600)
```

### Orchestration

- **Tool Used**: LangGraph orchestrates agent workflows to automate tasks like code generation and documentation management efficiently.
  
### AI Integration

- **Technology Used**: OpenAI GPT-4 powers the autonomous agent system for generating high-quality content including code snippets and FAQs.

## Common Troubleshooting Tips

1. **Issue**: Application not starting after deployment.
   - **Checklist**:
     - Ensure all environment variables are correctly set in Render.com settings.
     - Review logs in Render.com dashboard for any error messages during build or run time.

2. **Issue**: Database connectivity issues.
   - **Solution**:
     - Verify database credentials in the backend configuration.
     - Check if Row Level Security policies are correctly configured in Supabase.

3. **Issue**: Tasks not being processed by Redis Queue.
   - **Solution**:
     - Ensure Redis server is running and accessible by the backend application.
     - Check the RQ dashboard or logs for any failed jobs or errors.
