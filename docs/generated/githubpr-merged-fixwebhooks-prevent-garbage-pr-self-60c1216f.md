# Preventing Garbage PR Self-Trigger Loop in Webhooks

## Summary

This documentation addresses a critical fix implemented to prevent the generation of garbage Pull Requests (PRs) with malformed titles, specifically addressing the issue titled "fix(webhooks): prevent garbage PR self-trigger loop". The fix rectifies an issue where GitHub Continuous Integration (CI) events were incorrectly triggering the creation of unnecessary PRs due to a misinterpretation of event types.

### Root Cause

The root cause was identified as CI events (`check_suite`, `check_run`, `status`) sent by GitHub being parsed as `UNKNOWN` by our orchestrator. These `UNKNOWN` events were not being filtered by the `should_skip_orchestrator_pr_event()` function, which was designed to check for PR events only. As a result, these events were able to trigger the PR creation process through keyword matching, leading to the generation of malformed PR titles like "docs: Add githubunknown-docs-add-githubu (trace-id: webhook-)".

### Solution Implemented

The solution involved two key changes:

1. **Enhancing Event Parsing:** We revised the event parsing logic to accurately distinguish between relevant and irrelevant CI events, ensuring that only valid triggers lead to PR creation.

2. **Updating Skip Logic:** We extended the `should_skip_orchestrator_pr_event()` function to include checks against these newly identified event types, preventing them from inadvertently initiating the PR creation process.

#### Code Example

```python
# Enhancements in event parsing
def parse_github_event(event_payload):
    if event_payload.get("action") in VALID_CI_EVENTS:
        return "VALID_EVENT"
    else:
        return "UNKNOWN"

# Updated skip logic
def should_skip_orchestrator_pr_event(event_type, event_payload):
    if event_type == "UNKNOWN" or event_payload.get("title").startswith("docs: Add githubunknown"):
        return True
    return False
```

Replace `VALID_CI_EVENTS` with the actual list of CI event identifiers considered valid for triggering PR creations.
