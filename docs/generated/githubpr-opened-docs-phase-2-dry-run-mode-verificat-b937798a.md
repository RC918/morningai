# Verifying Phase 2 DRY_RUN Mode for GitHub Review Posting

This FAQ entry provides comprehensive details on verifying the functionality of the Phase 2 deployment concerning `ENABLE_GITHUB_REVIEW_POSTING=true` with `GITHUB_REVIEW_POSTING_DRY_RUN=true` in the MorningAI platform. The goal is to ensure that the DRY_RUN mode operates correctly, simulating GitHub Review Posting without making actual posts to GitHub. ## Explanation

The `DRY_RUN` mode is designed to test the GitHub review posting workflow without affecting live data or repositories. It's particularly useful during development or testing phases to validate changes without impacting actual GitHub repositories or workflows.

### Configuration Steps

1. **Enabling DRY_RUN Mode:**
   To enable DRY_RUN mode, you must set two environment variables in your deployment configuration:

   ```shell
   ENABLE_GITHUB_REVIEW_POSTING=true
   GITHUB_REVIEW_POSTING_DRY_RUN=true
   ```

2. **Deployment:**
   Ensure these settings are applied in your deployment environment. If you're using Render.com, these can be set under the Environment section of your service configuration.

3. **Verification:**
   After deploying your changes with the above environment variables set, monitor the worker logs to verify that the system attempts to post reviews without actually doing so.

## Troubleshooting Tips

1. **Not Seeing Simulated Posts in Logs:**
   - Ensure that both `ENABLE_GITHUB_REVIEW_POSTING` and `GITHUB_REVIEW_POSTING_DRY_RUN` are correctly set and deployed.
   - Verify that your logging level includes informational messages since simulated actions may not trigger warnings or errors.

2. **Environment Variables Not Taking Effect:**
   - Double-check your deployment configuration for typos.
   - Restart your service after making changes to environment variables.

3. **Unexpected Behavior Despite Correct Configuration:**
   - Review recent changes for any code that might bypass or ignore the `DRY_RUN` flag.
   - Check if any other environment variables or configurations could be interfering with the expected behavior.
