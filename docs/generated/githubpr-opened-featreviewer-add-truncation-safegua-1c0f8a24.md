# Handling Large PRs with Annotated Diff Truncation in MorningAI

## Summary

In MorningAI, we've introduced a robust solution to manage large Pull Requests (PRs) efficiently without overwhelming the Language Model (LLM) context window. This feature, available from PR #3097, implements a two-phase truncation safeguard specifically designed to handle annotated diffs in reviews for substantial PRs. The mechanism ensures that developers can review extensive changes effectively while adhering to the constraints of the LLM context window.

### Key Features:

- **Hybrid Truncation Strategy**: Combines aggressive context line reduction with strategic dropping of hunks/files to maintain readability and structural integrity.
- **Customizable Settings**: Introduces `LLM_REVIEW_MAX_DIFF_CHARS` for fine-tuning the maximum character count of diffs.

## Implementation Details

### Phase 1: Context Line Reduction

Initially, the system focuses on retaining only the lines adjacent to additions (`+` lines), significantly reducing the amount of text without losing critical context.

```python
# Simplified example of Phase 1 truncation
def truncate_context(diff):
    return [line for line in diff if line.startswith('+') or line_is_adjacent(line)]
```

### Phase 2: Dropping Hunks/Files

If the diff remains too large after Phase 1, the system will start dropping later hunks or files. This step ensures that earlier changes are prioritized and reviewed while keeping the overall structure understandable.

```python
# Example of Phase 2 truncation logic
def drop_later_hunks(diff, max_chars):
    truncated_diff = []
    char_count = 0
    for hunk in diff:
        if char_count + len(hunk) > max_chars:
            break
        truncated_diff.append(hunk)
        char_count += len(hunk)
    return truncated_diff
```

### Configuration

To customize the maximum diff character count, adjust the `LLM_REVIEW_MAX_DIFF_CHARS` setting in your configuration file:

```ini
[settings]
LLM_REVIEW_MAX_DIFF_CHARS = 80000  # Default: 80k characters (~20k tokens)
```

## Troubleshooting Tips

- **Issue**: Diff not truncating correctly.
  - **Solution**: Ensure `LLM_REVIEW_MAX_DIFF_CHARS` is set correctly and does not exceed LLM's maximum token limit.
- **Issue**: Missing critical changes due to truncation.
  - **Solution**: Adjust `LLM_REVIEW_MAX_DIFF_CHARS` to a higher value or manually review dropped hunks/files as necessary.
- **Issue**: Performance degradation with very large PRs.
  - **Solution**: Consider splitting extremely large PRs into smaller, more manageable chunks.

By implementing these strategies, MorningAI aims to streamline the code review process for large PRs while ensuring that reviews remain thorough and manageable.
