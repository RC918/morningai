# Add Export Functionality to Metrics Dashboard

MorningAI provides a robust metrics dashboard that enables users to monitor various performance indicators. Implementing an export functionality allows users to download these metrics for offline analysis, sharing, or archival purposes. This guide walks you through adding this capability to the MorningAI platform.

## Comprehensive Explanation

To add export functionality to the metrics dashboard, we'll leverage the backend Python Flask framework and integrate a frontend React component for initiating the export process. The process involves generating a CSV or Excel file from the metrics data stored in PostgreSQL (Supabase) and then providing a download link to the user.

### Backend Implementation

1. **Endpoint Creation**: Create a new Flask route dedicated to exporting data.

```python
# File path: morningai/backend/routes/metrics.py

from flask import Flask, send_file
import pandas as pd
from io import BytesIO
from your_metrics_module import get_metrics_data  # Make sure to replace this with your actual data retrieval module

app = Flask(__name__)

@app.route('/export_metrics', methods=['GET'])
def export_metrics():
    # Fetching metrics data from database
    metrics_data = get_metrics_data()

    # Convert data to DataFrame for easy manipulation/export
    df = pd.DataFrame(metrics_data)

    # Creating an in-memory bytes buffer for our Excel file
    output = BytesIO()
    with pd.ExcelWriter(output, engine='xlsxwriter') as writer:
        df.to_excel(writer, sheet_name='Sheet1')

    # Rewind the buffer
    output.seek(0)

    return send_file(output, attachment_filename="metrics_export.xlsx", as_attachment=True)
```

2. **Database Query**: Ensure your `get_metrics_data` function efficiently queries the PostgreSQL database using Supabase client or raw SQL queries, depending on your project setup.

### Frontend Implementation

1. **Export Button**: Add an export button in your React component where you display the metrics dashboard.

```jsx
// File path: morningai/frontend/components/MetricsDashboard.jsx

import React from 'react';
import axios from 'axios';

const MetricsDashboard = () => {

  const handleExport = async () => {
    const response = await axios.get('/export_metrics', { responseType: 'blob' });
    // Create a new Blob object using the response data of the file
    const blob = new Blob([response.data], { type: 'application/vnd.ms-excel' });
    // Create an anchor element and trigger download
    const link = document.createElement('a');
    link.href = window.URL.createObjectURL(blob);
    link.download = 'metrics_export.xlsx';
    link.click();
  };

  return (
    <div>
      <button onClick={handleExport}>Export Metrics</button>
      {/* Your dashboard content */}
    </div>
  );
};

export default MetricsDashboard;
```

## Common Troubleshooting Tips

- **Data Export Errors**: If you encounter issues during the data export process, ensure your query results are correctly formatted and compatible with pandas DataFrame.
- **File Download Issues**: If the file doesn't download or opens in a new tab instead, check that you've set the correct `responseType` in your Axios request and that you're properly creating a Blob in JavaScript.
- **Performance Concerns**: For large datasets, consider implementing server-side processing or pagination to avoid memory issues on both server and client sides.
