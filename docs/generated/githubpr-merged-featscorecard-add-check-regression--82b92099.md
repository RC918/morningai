## Summary of the Feature

The feature was introduced in PR #2864 and is designed to abstract regression detection logic previously embedded within workflow shell scripts into a testable Python function. ### Key Changes

- **`STATUS_SEVERITY` Constant**: A mapping that associates various statuses with a severity level, where a lower value indicates a preferable (better) status.
- **`check_regression` Function**: Accepts three parameters (`prev_status`, `curr_status`, `force_notify`) to determine if a regression has occurred and if notification is necessary.

### Code Example

Below is a simple example demonstrating how to use the `check_regression` helper:

```python
from scorecard import check_regression, STATUS_SEVERITY

prev_status = 'success'
curr_status = 'failure'
force_notify = False

# Check if there's a regression
is_regression, notify = check_regression(prev_status, curr_status, force_notify)

    print(f"Regression detected from {prev_status} to {curr_status}.")
    if notify:
        print("Sending notification...")
else:
    print("No regression detected.")
```
