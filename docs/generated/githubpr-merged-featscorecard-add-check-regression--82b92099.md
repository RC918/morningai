### Key Changes:
- Introduction of the `STATUS_SEVERITY` constant, which maps various statuses to their corresponding severity levels. A lower severity level indicates a better status.
- The `check_regression(prev_status, curr_status, force_notify)` function, which assesses whether a regression has occurred based on the previous and current status of the code.

### How It Works:

The `check_regression` function operates by comparing the severity level of the previous status of the code to that of the current status. If the current status represents a regression (i.e., its severity level is higher), the function triggers an alert or notification based on the `force_notify` parameter.

#### Code Example:

```python
# Define STATUS_SEVERITY mapping
STATUS_SEVERITY = {
    'success': 1,
    'warning': 2,
    'failure': 3,
}

def check_regression(prev_status, curr_status, force_notify=False):
    prev_severity = STATUS_SEVERITY.get(prev_status)
    curr_severity = STATUS_SEVERITY.get(curr_status)
    
    if curr_severity > prev_severity or force_notify:
        print(f"Regression detected: {prev_status} -> {curr_status}")
        return True
    return False
```
