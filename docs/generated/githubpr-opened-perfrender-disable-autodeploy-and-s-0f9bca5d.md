# Disabling AutoDeploy and Slimming Dependencies to Optimize Render Bandwidth Usage

## Summary

This FAQ addresses the steps taken in PR #2897 to mitigate a critical bandwidth crisis on Render, where 485GB out of an allocated 500GB was consumed, alongside a significant portion of pipeline minutes. The root cause identified was the high frequency of commits across multiple services triggering excessive builds due to `autoDeploy` being enabled.

### Changes Implemented:

1. **AutoDeploy Disabled**: The `autoDeploy` feature has been set to `false` for the following services to prevent unnecessary builds:
   - `braintrust-processor`
   - `morningai-orchestrator-api`
   - `morningai-worker-dashboard`
   - `morningai-ops-agent-worker`
   
2. **Slimming Dependencies**: Testing dependencies, which included heavy assets like Playwright browser binaries totaling over 150MB, were moved from the main `requirements.txt` to a separate file `requirements-dev.txt`.

## Implementation Details

### Disabling AutoDeploy

For each affected service, the Render configuration file (typically found at `.render/render.yaml`) was modified. Here’s how you can manually disable autoDeploy for a service:

```yaml
services:
  - type: web
    name: morningai-worker-dashboard
    env: python
    autoDeploy: false
```

Repeat this step for each service listed above.

### Slimming Dependencies

Dependencies solely required for testing or development were segregated into a separate file named `requirements-dev.txt`. This ensures that production builds do not install unnecessary packages, thereby reducing build size and time.

#### Original `requirements.txt` Example:

```plaintext
flask==1.1.2
pytest==6.2.4
playwright==1.10.0
```

#### Updated Files:

**requirements.txt**
```plaintext
flask==1.1.2
```

**requirements-dev.txt**
```plaintext
pytest==6.2.4
playwright==1.10.0
```

## Troubleshooting Tips

- **Builds Not Triggering**: After disabling autoDeploy, remember that deployments must be manually triggered through the Render dashboard or via webhook.
- **Dependency Errors**: If encountering issues with missing dependencies in your development or CI environments, ensure that you are installing packages from both `requirements.txt` and `requirements-dev.txt`.
- **Exceeding Bandwidth Limits**: Regularly monitor your Render usage dashboard to manage your bandwidth effectively. Consider further optimizations such as reducing asset sizes or cleaning up old builds.
