# Smart PR Filtering for Documentation Updates

## Summary

The introduction of smart PR filtering in the MorningAI platform aims to enhance the efficiency of documentation updates by reducing unnecessary noise from "garbage PRs". This feature ensures that only PRs requiring documentation changes trigger the generation of docs PRs, filtering out trivial changes like dependency updates or CI fixes.

### Filter Pipeline Overview

The smart PR filtering incorporates a two-step process to determine the relevance of a PR to documentation updates:

1. **Semantic Title Filter**: This initial filter quickly parses the PR title for specific prefixes that usually indicate non-documentation-related changes. The prefixes filtered out include `chore:`, `ci:`, `test:`, `docs:`, `style:`, and `build:`.

2. **File Path Filter**: Following the title filter, a more in-depth analysis checks the file paths affected by the PR. If the changes are outside the scope of documentation-relevant areas, the PR is skipped.

### Implementation Details

#### Semantic Title Filter

The semantic title filter can be implemented as part of a GitHub Actions workflow or within a custom webhook receiver in the backend (`/webhooks/github/pr`). Here's a simplified example:

```python
def should_skip_pr_based_on_title(pr_title):
    skip_prefixes = ['chore:', 'ci:', 'test:', 'docs:', 'style:', 'build:']
    return any(pr_title.startswith(prefix) for prefix in skip_prefixes)
```

#### File Path Filter

The file path filter requires fetching the list of modified files in a PR via GitHub's API and then checking if any of those files fall into documentation-related paths.

```python
from github import Github

def is_documentation_related(pr_files):
    doc_related_paths = ['docs/', 'guides/', '/README.md']
    return any(file.filename.startswith(tuple(doc_related_paths)) for file in pr_files)

g = Github("<YOUR_GITHUB_TOKEN>")
repo = g.get_repo("RC918/morningai")
pr = repo.get_pull(3060)  # Example PR number
pr_files = pr.get_files()

if not should_skip_pr_based_on_title(pr.title) and is_documentation_related(pr_files):
    print("This PR requires docs updates.")
else:
    print("No docs update needed.")
```

### Common Troubleshooting Tips

- **API Rate Limiting**: When implementing the file path filter, ensure to handle GitHub API rate limiting. Utilize conditional requests or cache responses where possible.
- **Incorrect Skipping**: If valid documentation-related PRs are being skipped, review your prefix list and path filters to ensure they're not overly broad.
- **Workflow Failures**: Ensure your GitHub Actions workflows or webhook receiver endpoints are correctly configured with valid credentials and error handling.
