## Explanation

However, due to a flaw in the implementation of the `_retry_with_backoff` method, exceptions raised during these operations were not properly cleared from memory after each retry attempt. This oversight led to an accumulation of exception references, particularly during periods of database instability, resulting in significant memory consumption and triggering OOM restarts in the affected worker.
