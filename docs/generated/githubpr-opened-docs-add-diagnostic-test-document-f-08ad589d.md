## Context

The 422 error typically occurs during code review processes when the MorningAI Reviewer Agent is unable to process a line of code due to various reasons such as syntax errors, merge conflicts, or incorrect file paths. ### Steps to Reproduce the Error

1. Ensure that your pull request does not use an `orchestrator/` branch prefix, as these are intentionally filtered out from triggering review processes.
2. Make sure that your pull request is based on the latest version of the main branch to avoid conflicts and outdated code references.

### Diagnostic Logging

To enable diagnostic logging for debugging:

```python

# Enable diagnostic logging
logging.basicConfig(level=logging.DEBUG)

# Example of logging at a key point

```

Replace `<PR_NUMBER>` with the actual number of your pull request.

### Capturing Diagnostic Logs

When a 422 error occurs, check the logs generated by the MorningAI Reviewer Agent. These logs are crucial for understanding what part of the code or review process is causing the issue.

#### Log Locations

- **Local Development**: `./logs/reviewer_agent.log`
- **Production**: Accessible via the monitoring dashboard under `Logs > Reviewer Agent`.

### Common Troubleshooting Tips

1. **Check for Syntax Errors**: Ensure there are no syntax errors in your pull request changes.
2. **Resolve Merge Conflicts**: Before submitting a PR, rebase onto the latest main branch and resolve any merge conflicts.
3. **Verify File Paths**: Make sure all referenced file paths in your changes exist and are correctly spelled.
4. **Review Diagnostic Logs**: Look into the diagnostic logs for any specific errors or warnings that might indicate what went wrong.
